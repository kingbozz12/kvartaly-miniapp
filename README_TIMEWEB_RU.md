# КВАРТАЛЫ — сборка для Timeweb Cloud App Platform (v0.1.3)

Простой тестовый Telegram Mini App: город, герой, тренировки, бои с боссом, карта. Исходники только на Node.js, без необходимости устанавливать Redis или PostgreSQL для закрытого демо.

## 1. Git-репозиторий
1. Создайте **приватный** репозиторий на GitHub (например, `kvartaly-miniapp`).
2. Загрузите именно *содержимое этой папки* в **корень** репозитория: `Dockerfile`, `package.json`, `server.mjs`, `public/`, `tests/`, `.gitignore`, `.dockerignore`. Убедитесь, что `Dockerfile` лежит рядом с `package.json`, а не внутри дополнительной папки.
3. Не загружайте токен, `.env` или папку `data/`.

## 2. Timeweb Cloud
1. В панели Timeweb Cloud откройте **App Platform → Создать приложение**.
2. Подключите GitHub, дайте доступ только нужному приватному репозиторию и выберите ветку `main`.
3. Выберите **Dockerfile** (не «статический сайт» и не «Frontend»), регион РФ и минимальную конфигурацию Backend App, достаточную для тестов.
4. Путь к директории проекта — корень репозитория (обычно пустое поле). Dockerfile — в корне; порт контейнера — **3000** (`EXPOSE 3000`).
5. В дополнительных настройках задайте **переменную окружения** `TELEGRAM_BOT_TOKEN` = новый, не раскрытый токен @KvartalyGameBot. Для `NODE_ENV` можно явно указать `production`, хотя Dockerfile уже задаёт его.
6. Нажмите «Запустить деплой». После запуска проверьте **Деплой** и **Логи приложения**, затем откройте технический HTTPS-домен из «Дашборда».
7. Проверьте `https://ВАШ-ДОМЕН/healthz` — ожидаемый ответ: `{"ok":true,"demo":false}`.

## 3. Telegram
В @BotFather: `/setmenubutton` → @KvartalyGameBot → вставьте полученную HTTPS-ссылку → подпись `🎮 Играть`. Проверьте игру по кнопке в Telegram. Не тестируйте игровые API из обычного браузера: они требуют подписанные `initData` Telegram.

## 4. Важные ограничения
**Только закрытое тестирование.** Сервер сохраняет игровой прогресс в `data/store.json` *внутри контейнера*. На Timeweb App Platform данные контейнера могут быть удалены при повторном деплое, поэтому прогресс может пропасть. До приглашения настоящих игроков необходимо подключить PostgreSQL/внешнее хранилище и резервное копирование. `TELEGRAM_BOT_TOKEN` держите только в настройках окружения Timeweb, никогда не размещайте в GitHub. Старый токен, показанный в чате, должен быть отозван через @BotFather.

## 5. Локальная проверка
При установленном Node.js 20+:
- `npm.cmd run dev` — локальный деморежим (только на вашем ПК).
- `npm.cmd test` — тесты Telegram-авторизации.
- `npm.cmd start` — сервер с проверкой Telegram initData; нужен токен в переменной окружения.
